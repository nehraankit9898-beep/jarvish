> `agentscope-suite/studio`. Every status below is backed by a command that was
> actually executed in this environment (see `docs/TEST_RESULTS.md`).
>
> * **Implemented & Verified** — code exists *and* was executed successfully.
> * **Implemented, Not Verified** — code exists, no runtime evidence in this
>   environment (usually needs a paid API key / GPU / external service).

>   is missing.
> * **Broken** — present but non-functional.
> * **Missing** — no implementation at all.
> * **Blocked** — cannot be implemented/verified because of credentials,
>   services, dependencies or hardware.

> executed), `docs/TEST_RESULTS.md` (the measured results),

## 2. Confirmed defects found in the baseline (fixed during this task)

| # | Severity | Defect | Fix |
|---|---|---|---|
| D1 | **Critical** | `POST /api/opencode/execute` had no authentication and spawns a child process | `rejectIfUnauthorized` applied; approval + audit |
| D2 | High | `POST/PUT/PATCH/DELETE /api/agent-registry/*` had no authentication | `rejectIfUnauthorized` applied |
| D3 | Medium | `GET /api/opencode/detect` had no authentication | `rejectIfUnauthorized` applied |
| D4 | Medium | No audit trail for privileged actions | new `AuditLog` model + writer + `/api/audit` reader |
| D5 | High | No server-side provider management (enable/disable, priority, free-only) | new `ProviderConfig` model + `/api/providers/**` |
| D6 | High | Free-model policy existed only as a static `free` flag and was never enforced | free-only enforcement in the router + provider store |
| D7 | Medium | No memory / knowledge / automation subsystem | new models + APIs + UI panels |
| D8 | Low | `next.config.ts` emitted a deprecation warning (`middleware` → `proxy`) on Next 16 | renamed to `proxy.ts` |
| D9 | **High** | `spawn()` without an `error` listener → an **uncaught exception** when the OpenCode binary is missing (the normal case) | the promise now resolves on `error` (`src/lib/agentic/opencode.ts`) |
| D10 | **High** | The approval gate could be bypassed by posting an arbitrary `approvedCommands` list | only the engine's `pendingCommand` may be approved (`src/lib/agentic/approvals.ts`) |
| D11 | Medium | The cancel route did not stop a running OpenCode child process | `cancelOpenCodeTask(id)` is called |
| D12 | Medium | The standalone production server could not find the database (a relative `DATABASE_URL` is resolved against the *bundled* schema) | `scripts/start-prod.mjs` rewrites it to an absolute path |
| D13 | Medium | The browser could not talk to a token-protected server (every call would be 401) | `src/lib/api-token.ts` sends `x-agentscope-token`; the token is entered in the System panel |
